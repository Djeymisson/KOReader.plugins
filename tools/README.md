# Development tools

Tools for working on the plugins in this repository. Nothing here is part of a
plugin: the release zips contain only the `.koplugin/` folders, so none of it is
shipped or installed on a device.

| Folder | What it is |
|---|---|
| [`dictionaryexplorer/`](./dictionaryexplorer/README.md) | Tests, performance budgets and benchmarks for the Dictionary Explorer plugin, run inside a real KOReader without a window |
